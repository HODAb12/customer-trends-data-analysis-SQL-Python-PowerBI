# Customer Shopping Behavior Analysis | Python, SQL & Power BI

This project explores customer shopping behavior through an end-to-end data analytics workflow. It focuses on transforming raw customer data into meaningful insights by combining data analysis, SQL querying, visualization, and reporting.

## 📌 Project Overview

The project covers the main stages of a data analytics process:

- **Data Exploration & Preparation (Python):** Explore, clean, and prepare customer shopping data for analysis.
- **Data Analysis (SQL):** Investigate purchasing patterns, product preferences, customer segments, and discount usage through SQL queries.
- **Data Visualization (Power BI):** Present key metrics and trends through an interactive dashboard.
- **Reporting & Presentation:** Summarize the analysis, highlight key findings, and communicate insights through a written report and presentation.

## 🎯 Project Objectives

- Understand customer purchasing behavior and preferences.
- Identify popular product categories and shopping trends.
- Analyze discount usage and customer spending patterns.
- Extract business insights to support data-driven decisions.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/HODAb12/customer-trends-data-analysis-SQL-Python-PowerBI.git
```

2. Open `Customer_Shooping.ipynb` in Jupyter Notebook.
3. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

4. Run the notebook to explore and analyze the dataset.
5. Execute the SQL queries in `database_customer.sql` using a compatible SQL environment.
6. Open the `.pbix` file with Power BI Desktop to explore the dashboard.
